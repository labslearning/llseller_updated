# 🚀 Sovereign B2B Intelligence Engine

Sistema avanzado de prospección y enriquecimiento de leads utilizando OSINT, Playwright y DeepSeek AI.

## 🛠️ Tech Stack
- **Backend:** Django 5.x
- **UI:** Unfold Admin (Tailwind CSS)
- **Async:** Celery + Redis
- **Automation:** Playwright (Stealth Mode)
- **AI:** DeepSeek-Chat / GPT-4o

## ⚡ Instalación
1. Clonar: `git clone ...`
2. Instalar dependencias: `pip install -r requirements.txt`
3. Playwright setup: `playwright install chromium`
4. Migraciones: `python manage.py migrate`

## 📡 Centro de Mando
